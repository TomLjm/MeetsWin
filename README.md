## 这是什么

面翼 MeetsWin 是一款桌面端 AI 面试陪练工具，帮你把每一次面试都变成一次有反馈的训练：

- **模拟面试**：上传简历 + 岗位 JD，AI 扮演面试官逐题提问，每题给出评分与建议，结束输出完整复盘；
- **简历优化**：上传简历与目标 JD，AI 给出匹配度评分（0–100）与逐项修改建议，产出改后简历；
- **实战演练模式**：面试前用真实问答节奏演练表达，提升临场反应；
- **面试记录**：所有练习自动落盘，随时回看复盘。

适用于：秋招 / 春招 / 实习 / 社招，中英文双语，支持个性化面试风格。
